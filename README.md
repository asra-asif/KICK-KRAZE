## 👟 About The Project

**KICK KRAZE** is a premium football cleats e-commerce landing page built to showcase high-performance football boots with a bold, energetic design. It brings together clean visuals, smooth scroll animations, and an athlete-grade aesthetic to deliver a top-tier shopping experience.

Whether you're a professional striker or a weekend warrior, Kick Kraze has cleats engineered for every play style — from lightning speed to iron control.

> *"Where Performance Meets Passion!"*

## ✨ Features

| Feature | Description |
|--------|-------------|
| 🦸 **Hero Section** | Bold full-page hero with transparent football boots imagery and CTA |
| 👟 **About Us** | Two-column layout with brand story and pitch action photography |
| 🛒 **Featured Cleats** | 6-product grid (2 rows of 3) with pricing and Buy Now CTAs |
| 🖼️ **Customer Gallery** | 9-image responsive grid showcasing football boot photography |

| 📬 **Contact Section** | Side-by-side contact info + validated contact form |
| 🍔 **Offcanvas Menu** | Mobile-responsive slide-out navigation drawer |
| 📜 **Scroll Animations** | IntersectionObserver-powered section reveal on scroll |
| 🎨 **Montserrat Typography** | Premium Google Font for a sporty, modern aesthetic |

## 🛠️ Getting Started

No build tools or package managers needed — just open in a browser!

### Prerequisites

- Any modern web browser (Chrome, Firefox, Edge, Safari)
- A code editor like [VS Code](https://code.visualstudio.com/)
- Optionally: [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) for hot reload

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/your-username/KICK-KRAZE.git

# 2. Navigate to the project folder
cd KICK-KRAZE

# 3. Open index.html directly in a browser
#    OR use Live Server in VS Code for the best experience
```

> All CDN dependencies (Bootstrap, Font Awesome, jQuery, Google Fonts) are loaded automatically — no `npm install` needed! 🎉

## 🎨 Design System

```css
/* Color Palette */
--primary-accent:  #e63946   /* Bold red — energy & urgency */
--cta-button:      #custom   /* Brand CTA button */
--background:      #ffffff   /* Clean white base */
--text-dark:       #212529   /* Bootstrap dark text */
--text-muted:      #6c757d   /* Bootstrap muted */
```

**Key Design Choices:**
- 🏃 **Action-first layout** — big hero with immediate CTA gets users shopping
- 📱 **Bootstrap Offcanvas** — elegant mobile nav experience
- 👀 **Scroll reveal animations** — IntersectionObserver for cinematic section entrances
- ⭐ **Carousel testimonials** — social proof from 6 top footballers
